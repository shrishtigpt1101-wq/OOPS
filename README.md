# OOPS

This repository contains C++ practice questions and Object Oriented Programming lab assignments. The programs are organized assignment-wise in folders named `A1`, `A2`, `A3`, and so on.

## Repository Structure

| Folder | Contents |
| --- | --- |
| `A1` | Basic class and object programs |
| `A2` | C++ practice programs using classes, methods, and simple logic |
| `A3` | Functions, default arguments, inline functions, and references |
| `A4` | Static members, stack, queue, area, volume, and related programs |
| `A5` | Object oriented programming practice problems |
| `A6` | Additional C++ class-based programs |
| `A8` | OOP assignment programs |
| `A9` | OOP assignment programs |
| `A10` | OOP assignment programs |
| `A11` | Practice and test programs |
| `A12` | File handling and I/O stream programs |

> Note: Folder `A7` is not present in the current workspace.

## File Types

- `.cpp` / `.CPP` files contain the C++ source code.
- `.exe` files are compiled Windows executables generated from the source files.
- `.txt` files are sample/input data files used by file handling programs.

## How to Compile

Use any C++ compiler such as `g++`.

```bash
g++ A1/Q1.cpp -o A1/Q1
```

For Windows PowerShell:

```powershell
g++ A1\Q1.cpp -o A1\Q1.exe
```

## How to Run

After compiling, run the executable:

```powershell
.\A1\Q1.exe
```

## Requirements

- C++ compiler, such as GCC/G++ or MinGW
- Windows, Linux, or macOS terminal

## Purpose

The repository is intended for storing and submitting OOPS lab work, including assignment-wise C++ programs and related files.
